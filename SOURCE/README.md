# Adaptive GLB Viewer V2.19 Source

V2.19 keeps the object-centred orbit introduced in V2.18 and restores deliberate
viewport panning for close inspection. Right-drag moves the view on desktop;
two-finger movement pans on touch devices. Reset View returns to the exact fitted
model centre.

The studio shadow is now layered: a compact dark contact core, a soft local
falloff, and a lower-opacity key-light shadow that fades with ground distance.
